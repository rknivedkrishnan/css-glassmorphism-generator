# Glassmorphism CSS Generator 🔮

An interactive, zero-dependency tool to design modern "frosted glass" UI elements and generate the CSS instantly.

[![Live Demo](https://img.shields.io/badge/demo-live-green.svg)](https://glassmorphismgenerator.vercel.app/)
![License](https://img.shields.io/badge/license-MIT-blue.svg)


## ✨ Features

-   **Real-time Preview**: See your glass effect update instantly as you tweak settings.
-   **Customizable**: Adjust blur amount, transparency, background color, outline width, and border radius.
-   **One-Click Copy**: Get the exact CSS code snippet copied to your clipboard.
-   **Dark Mode UI**: Designed with a sleek, developer-friendly interface.
-   **Zero Dependencies**: Pure HTML, CSS, and Vanilla JavaScript. No `npm install` required.

## 🚀 Quick Start

### Try it Live

**[Launch the tool here →](https://glassmorphismgenerator.vercel.app/)**

### Run Locally

You can also run this tool directly from your browser without installing anything:

1.  Clone this repository or download the ZIP.
2.  Open the folder.
3.  Double-click `index.html` to launch.

## 🛠️ Usage

1.  **Blur**: Drag the slider to control the frost intensity (`backdrop-filter: blur()`).
2.  **Transparency**: Adjust the opacity of the glass background color.
3.  **Color**: Pick a base tint for your glass (white is standard, but try colors!).
4.  **Outline**: Add a subtle border to enhance the glass edge definition.
5.  **Copy CSS**: Click the "Copy" button and paste the code into your project's stylesheet.
